# Visual-Identity

Tetra.Earth visual identity: Tetrahedron G, logos, patterns, brand guide, and public design skills.

## Start here

- Human / agent spec: [brand/GUIDE.md](brand/GUIDE.md)
- Live visual guide: `npm install && npm run dev`
- Tokens: [brand/tokens.css](brand/tokens.css) · [brand/tokens.json](brand/tokens.json)
- Chrome: [brand/chrome.css](brand/chrome.css) · [brand/chrome.js](brand/chrome.js)
- Mark: [brand/geometry/tetrahedron-g.svg](brand/geometry/tetrahedron-g.svg)

## Skills

Public, for anyone designing Tetra apps:

- `.cursor/skills/tetra-brand` — identity, mark, color, type, builds
- `.cursor/skills/tetra-vite-ui` — Vite chrome (bar → triangle, dock, footer)
- `.cursor/skills/tetra-pdf` — print / PDF

## Build types

`vite-ui` (default apps) · `vite-site` (landings, this guide) · `vite-pdf` · `mark`

## Plates

`Logos/` · `Backgrounds-and-Patterns/` · `Ready-Images/`
